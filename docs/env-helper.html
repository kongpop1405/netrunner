🤖 NetRunner — ตัวช่วยสร้างไฟล์ .env

ตอบทีละข้อ เดี๋ยวหน้านี้ประกอบไฟล์ .env ให้เอง ไม่ต้องพิมพ์อะไรเป็นโค้ด

💡 ปกติไม่ต้องมี .env เลย — บอทหา adb กับ emulator ให้เองอัตโนมัติ ใช้หน้านี้เฉพาะเมื่อ (1) เปิด LDPlayer หลายตัวพร้อมกัน (2) บอทหา adb ไม่เจอ หรือ (3) อยากได้แจ้งเตือน Discord

1 ADB_PATH — โปรแกรม adb อยู่ที่ไหน

เปิด File Explorer แล้วไปดูโฟลเดอร์ C:\LDPlayer ว่าข้างในชื่อ LDPlayer อะไร

2 NETRUNNER_DEVICE — emulator ตัวไหน

ตั้งเฉพาะเมื่อเปิด LDPlayer หลายตัวพร้อมกัน — เปิดตัวเดียวข้ามข้อนี้ได้เลย

สูตร: port = 5555 + (2 × index)
→ 127.0.0.1:5555

กด Win + R พิมพ์ cmd กด Enter แล้ว copy คำสั่งนี้ไปวาง (LDPlayer ต้องเปิดอยู่): 

"C:\LDPlayer\LDPlayer14\adb.exe" devices

3 DISCORD_WEBHOOK_URL — แจ้งเตือนเวลาบอทค้าง/พัง (ไม่บังคับ)

ใน Discord: คลิกขวา channel → Edit Channel → Integrations → Webhooks → New Webhook → Copy Webhook URL

✓ ไฟล์ .env ของคุณ

copied ✓
วิธีเอาไฟล์ไปวาง (ถ้าใช้ปุ่ม Copy)
  1. เปิด Notepad แล้ววาง (Ctrl+V)
  2. File → Save As → ไปที่โฟลเดอร์ netrunner
  3. ช่อง File name พิมพ์ ".env" พร้อมเครื่องหมายคำพูด
  4. ช่อง Save as type เลือก All Files → Save

ถ้าใช้ปุ่มดาวน์โหลด: ย้ายไฟล์ที่ได้ไปไว้ในโฟลเดอร์ netrunner — ถ้าชื่อไฟล์กลายเป็น env เฉย ๆ ให้เปลี่ยนชื่อเป็น .env (มีจุดนำหน้า)
