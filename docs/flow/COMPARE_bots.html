06 เลือกตัวไหนดี

Boost spend risk — ใครเผาเหรียญบ้าง

เกณฑ์เลือกที่มักลืม: บอทส่วนใหญ่ ซื้อ boost ทุก run ผ่าน Multi-Buy auto-roll ซึ่ง roll จนกว่าจะได้ boost ที่ปักไว้ — เหรียญหมดกลาง roll ก็มี (insufficient_coins → Cancel → เล่นต่อแบบไม่มี boost).

11 ✅ 2026-08-04 — ทำไม toggle ไม่กด relay ทั้งที่ coinrun กดทุกครั้ง

อาการ: coinrun กด Cookie Relay ได้ปกติ แต่ boxrun_toggle ไม่กดเลยสักครั้ง ทั้งที่ config มี relay chain ครบเหมือนกัน (8 state) และ --relay y ก็ส่งไปแล้ว. ไม่ใช่บั๊กของ relay chain — เป็น engine optimization ที่ชนกับ hop ที่ไม่มี action เหลืออยู่.

สาเหตุ — เฟรมค้าง (stale frame) เมื่อ hop เหลือแต่ goto

src/fsm.py ตัดสินว่าจะ grab เฟรมใหม่หรือใช้เฟรมเดิม จาก "state นี้ทำ action อะไรหรือเปล่า":

hop มีอะไรใน on_absentengine ทำอะไรต่อrelay chain เห็นอะไร
['jump', 'goto']
(jump/slide เปิด)		 ทำ action → frame = None → grab เฟรมใหม่ + sleep ตาม poll ภาพสดทุก hop ✓
['goto']
(jump/slide ปิด)		 did_transition = True → ใช้เฟรมเดิมที่ cache ไว้ ไล่ goto ต่อจนกว่า pure-goto chain จะยาวเกินจำนวน state (83) ถึงจะ re-grab ภาพนิ่งใบเดิม ✗

Cookie Relay prompt อยู่บนจอแค่ ~2–3 วินาที — toggle ที่ปิด jump/slide จึงตรวจแต่เฟรมที่ถ่ายไว้ก่อน prompt โผล่ วนซ้ำใบเดิม ไม่มีทางเจอ. ส่วน coinrun รันผ่าน main.py ไม่มีใคร strip อะไรออก hop จึงมี jump ครบ → เฟรมสดทุกครั้ง → กดติดทุกรอบ.

หลักฐานจาก live log — ฝั่งที่ jump เปิด (boxrun_magnet) score ของ relay_prompt_marker เปลี่ยนทุก hop: 0.35 → 0.40 → 0.33 (13 ค่าไม่ซ้ำกันตลอด run) = เฟรมใหม่จริง. ถ้าเป็นเฟรมค้าง score จะซ้ำเป๊ะทุกครั้ง เพราะ matchTemplate เป็น deterministic.

ที่มาของสถานะนี้

launchers/boxrun_toggle.bat เคย hardcode set "JUMPSLIDE=n" พร้อม comment ว่า "prompt hidden for now — both run actions default off" และ comment prompt ทิ้ง (ผู้ใช้เลือกไม่ได้ตอนรัน). ตอนตั้งค่านั้น relay ยังเป็น blind tap ที่ไม่ทำงานอยู่แล้ว จึงไม่มีใครเห็นผลข้างเคียง — พอ relay chain ใช้ได้จริง (§10) ผลข้างเคียงถึงโผล่.

แก้แล้ว

JUMPSLIDE=y + comment เตือนไว้ในไฟล์ว่าห้ามตั้งเป็น n พร้อมเหตุผล. ตรวจแล้วทุก hop กลับมามี action:

กับดักที่ยังเหลือ — run_toggle.py ยังยอมให้ --jump n --slide n ผ่านได้เงียบ ๆ ซึ่งจะสร้างสถานะเดิมซ้ำ. ยังไม่มี guard เตือนตอน strip แล้ว hop เหลือ goto ล้วน — เป็นงานที่ค้างไว้.
