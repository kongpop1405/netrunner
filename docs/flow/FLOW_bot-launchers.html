NetRunner — โฟลวบอทแต่ละตัว

10 launcher (.bat) → config → state-machine flow · Cookie Run: OvenBreak
10 launchers 3 กลุ่ม FSM engine เดียว config = พฤติกรรม

ทุกบอทใช้ engine ตัวเดียวกัน (src/fsm.py — capture → perceive → act loop). ความต่างอยู่ที่ config JSON ล้วน: บอทคนละตัว = state machine คนละชุด. .bat แค่เลือก config + ถาม flag แล้วเรียก main.py. แบ่งเป็น 3 กลุ่มตามงาน.

02โฟลว Box-Farm (6 ตัว — spine ร่วม)

วงหลัก: home → เคลียร์ popup → ซื้อ boost → รอ heart → เล่น → เปิดกล่อง → กลับ home. ก่อนแตะ Play! ทุกครั้งมี gate 2 ชั้น (verify_no_popup / verify_no_sendlife) กัน tap ทะลุ popup ที่บัง Play! อยู่.

วงหลัก boost / กล่อง (ต่อ variant) popup gate / recovery gate ทั่วไป absent path
