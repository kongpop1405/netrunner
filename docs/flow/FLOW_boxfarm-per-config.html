วงหลัก boost / กล่อง gate / hop

boxrun_default.bat

boost: speed relay ✓early quit48 states

โครงเหมือน boxrun_magnet เป๊ะ — เปลี่ยน 2 จุด: boost = +17% speed และ quit เร็ว พอได้กล่อง.

buy_speed แตะ Multi-Buy โดยตรง (ไม่ต้องเปิด Random Boost cell ก่อน = ประหยัด 1 tap+wait เทียบ magnet) · check_box absent → running (ยังไม่ได้กล่อง เล่นต่อ), เจอ box → quit_run บีบออกทาง pause menu บันทึกกล่อง

vs boxrun_magnet: boost magnet→speed (buy_speed แตะ Multi ตรง 1 tap แทน 2) · เพิ่ม check_box → quit_run = เจอกล่องแล้วควิทเลย ไม่เล่นจนตาย

boxrun_speed_quit2.bat

boost: speed relay ✓quit-after-247 states

variant ของ boxrun_magnet (โครง jump-hops + speed boost) แต่ควิทหลังได้ 2 กล่อง ต่อ session.

vs boxrun_default: เหมือนกันเกือบหมด (speed + quit + jump hops) — ต่างที่ episode 4 และ threshold ของ quit (--quit-after-boxes 2 ผ่าน BoxQuitRunner: นับกล่องข้าม run จน 2 ใบค่อยควิท ไม่ใช่ควิททันทีที่เจอใบแรก). โครง state เหมือน ep3.
quit-after-N คุมที่ Python (BoxQuitRunner ใน run_toggle.py) ไม่ใช่ state — อ่านเลขกล่องจาก OCR (--quit-after-boxes) ถ้ามี tesseract, ไม่งั้นนับ run ที่มีกล่องแบบหยาบ.

boxrun_passive.bat

boost: none guard loop early quit36 states

โครง in-run ต่างจากตัวอื่นทั้งหมด — ไม่มี jump_* เลย. auto-play ล้วน + guard chain เช็ค popup ระหว่างรัน. ไม่ซื้อ boost.

วงหลัก guard loop (แทน jump) absent (ยังรัน)
vs boxrun_magnet: ไม่มี jump_2/3/4 — in-run เป็น running ที่ absent (result ยังไม่ขึ้น) → ไล่ guard chain (home? shop? sendlife? inactive?) → check_box. ไม่ซื้อ boost (await_shop → check_heart ตรง). ไม่ relay. 36 state (น้อยสุด)

boxrun_speed_noquit.bat

boost: speed relay ✗ ไม่ quit47 states

Clone ของ ep3 (speed + jump hops) แต่ถอด 2 อย่าง: ไม่ tap relay ระหว่างรัน และ ไม่ควิทเร็ว — เล่นยาว.

vs boxrun_default: jump hops ไม่มี relay_tap (jump_2/3/4 ถอด relay ออก) · quit_run มีอยู่แต่ ไม่มีใครชี้เข้า (check_box → check_shop_after_run แทน quit_run) = ไม่ควิท. เหมาะเก็บกล่องรัวยาว ๆ ไม่ bail
ระวัง: ชื่อ variant บอกเจตนาชัด — ห้ามต่อ quit_run กลับ (จะขัดชื่อ). relay ถอดจงใจ (relay เคยเป็นแหล่ง stray leaderboard tap)

boxrun_passive_3boost.json (no .bat — main.py)

3 boosts: HP+clock+x2 guard loop relay ✗ quit at box target35 states

vs boxrun_passive: เพิ่ม buy_boosts (แตะ 3 shop tile: HP potion + clock + x2, 800 เหรียญ/ตัว, tile ที่ซื้อแล้ว no-op) · in-run เหมือนกันเป๊ะ (guard loop). vs boxrun_magnet: คนละเรื่อง — passive ไม่ใช่ jump-hops, boost เป็น tile ไม่ใช่ Magnetic Aura roll

boxrun_magnet_quit3.json (no .bat — main.py)

magnet guard loop relay ✗ quit at 3 boxes37 states

Magnetic Aura boost แต่ in-run เป็น passive (ต่างจาก boxrun_magnet ที่เป็น jump-hops) · ควิทที่กล่องที่ 3 (ใช้ ep6 box counter template).

vs boxrun_magnet: in-run passive แทน jump-hops (magnet เป็น jump J→S→J, ตัวนี้ auto-play + guard loop) · เพิ่ม quit-at-3 (ตัว magnet เล่นจนตาย). vs boxrun_passive: ซื้อ magnet (passive ไม่ซื้อ boost)

coinrun.bat

boost: doublecoins relay ✓เล่นจนตาย47 states

โครง jump-hops เหมือน ep6 แต่เป้าหมายคือ เหรียญไม่ใช่กล่อง — ซื้อ Double Coins. มี boost-guard พิเศษ.

probe_dc_owned: Multi-Buy ยิงเฉพาะตอน Double Coins ยังไม่ equipped (กันซื้อซ้ำเปลืองเหรียญ)

vs boxrun_magnet: boost magnet→doublecoins ผ่าน guard probe_dc_owned (เช็คว่ามี Double Coins แล้วหรือยังก่อนซื้อ = กันซื้อซ้ำ) · ไม่มี early quit · ใช้กับ episode ไหนก็ได้ (ไม่ผูก episode)

boxrun_toggle.bat (toggle)

ep ไหนก็ได้boost: ถามตอนรัน relay: ถามquit: ถาม62 states (มากสุด)

ตัวเดียวที่ถาม flag ตอนรัน — ผ่าน tools/run_toggle.py patch config ใน memory ก่อนส่งเข้า engine. + เปิด anti-detection ครบ (pacing/reset/lives).

flag → config patch: boost X → apply_boost (probe/buy/picker detect+taps เปลี่ยน) · jump=n → strip jump actions · relay=n → strip relay_tap · faststart=n → strip faststart_tap · quit=N → BoxQuitRunner.quit_after.
+ anti-detection ใน JSON: poll/wait jitter · inter_game_delay · session_reset · periodic_routines (lives)

vs ทุกตัว: ไม่ hardcode boost/quit/relay ใน config — ถามตอนรันแล้ว patch. โครง state = superset (ทั้ง jump hops + check_box + lives_* chain) · เป็นตัวเดียวที่มี session_reset_s + periodic_routines + pacing jitter (Phase 1/2/5 เปิดที่นี่ก่อน)
