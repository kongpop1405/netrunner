02โฟลว Box-Farm (วงหลักร่วม)

วงหลัก: home → เคลียร์ popup → (ซื้อ boost) → รอ heart → เล่น → เปิดกล่อง → กลับ home. ก่อนแตะ Play! มี gate 2 ชั้น (verify_no_popup / verify_no_sendlife) กัน tap ทะลุ popup ที่บัง Play!.

37/62 state เหมือนกันหมด — spine (home→gates→check_heart→running→mb_open→home) + popup recovery + guard chain + jump hops. ต่างแค่ 3 จุด: boost อะไร · ควิทมั้ย · มี lives routine มั้ย. boxrun_toggle = superset (มีทั้ง 3 แล้วเลือกเปิด/ปิดผ่าน flag ตอนรัน).
In-run ของ 4 ตัวนี้ = jump hops ทั้งหมด (jump_2→jump_3→jump_4 วน J→S→J). โครง guard loop (ไม่มี jump) มีเฉพาะใน archived passive variants.

boxrun_default — ตัวเริ่มต้น

no boost jump hopsrelay ✗ quit ที่ 1 กล่อง40 states

ตัว default — ไม่ซื้อ boost (Fast Start อย่างเดียว), jump-hop run (ไม่ tap relay), ควิททันทีที่ได้กล่องแรก. minimal ไม่พึ่ง shop.

vs boxrun_magnet: เอา buy chain ออกทั้งชุด (probe/buy/picker/wait_roll/... ลบหมด) · await_shop/boost_shop → check_heart ตรง · เพิ่ม check_box → quit_run (magnet เล่นจนตาย). In-run = jump hops เหมือน magnet แต่ถอด relay_tap ออก (jump_2/3/4 + guard_not_inactive ไม่ tap Cookie Relay)

boxrun_magnet

boost: magnet jump hopsrelay ✓ เล่นจนตาย45 states

ซื้อ Magnetic Aura ทุก run (Random Boost + Multi-Buy auto-roll) · jump-hop run · เล่นจนตายเก็บกล่อง.

baseline ของ jump-hops. boxrun_default = ตัวนี้ลบ buy chain + เพิ่ม quit; coinrun = ตัวนี้เปลี่ยน boost เป็น Double Coins

boxrun_toggle

ep ไหนก็ได้boost: ถามตอนรัน relay: ถามquit: ถาม62 states (มากสุด)

ตัวเดียวที่ถาม flag ตอนรัน — ผ่าน tools/run_toggle.py patch config in-memory ก่อนส่งเข้า engine + เปิด anti-detection ครบ (pacing/reset/lives).

flag → config patch: boost X → apply_boost · jump=n → strip jump · relay=n → strip relay_tap · quit=N → BoxQuitRunner.quit_after. + anti-detection ใน JSON: poll/wait jitter · inter_game_delay · session_reset · periodic_routines (lives).

vs ทุกตัว: ไม่ hardcode boost/quit/relay — ถามตอนรันแล้ว patch. โครง state = superset (jump hops + check_box + lives_* chain) · เป็นตัวเดียวที่มี session_reset + periodic_routines + pacing jitter

coinrun

boost: doublecoins jump hopsrelay ✓ เล่นจนตาย47 states

โครง jump-hops เหมือน magnet แต่เป้าหมาย เหรียญไม่ใช่กล่อง — ซื้อ Double Coins ผ่าน guard พิเศษ.

vs boxrun_magnet: boost magnet→doublecoins ผ่าน guard probe_dc_owned (เช็คว่ามี Double Coins แล้วก่อนซื้อ = กันซื้อซ้ำ) · ไม่มี early quit

03โฟลว Utility (จบแล้ว stop)

ต่างจาก box-farm: ทำงานจนหมดแล้วหยุด ไม่วน farm. ไม่มี boost/heart/run.

giftdraw — เปิดกล่อง Gift Draw

sendlife — ส่ง life ให้เพื่อน

sendlife ถูก graft เข้า boxrun_toggle แล้ว (Phase 5) เป็น lives_* states — เรียกทุก 25–35 นาที ระหว่าง farm ผ่าน periodic_routines. sendlife.bat = รันแยกครั้งเดียวจบ.

addfriend — ส่ง friend request

xpstat (test account) ไม่มี .bat — รันตรง python main.py --config config/cookierun/xpstat.json. โครงเหมือน box-farm แต่ไม่ซื้ออะไรเลย (coin คงที่ วัด XP/run ได้สะอาด). NEVER point ที่ main account.
