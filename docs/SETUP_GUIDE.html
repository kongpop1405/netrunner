Setup Guide

Full walkthrough for getting the farm bots running on a new machine — from cloning the repo to your first live run. Follow the steps in order; each one gates the next.

1 Clone to an ASCII path — no OneDrive

Clone (or copy) the repo somewhere with a plain-English path, e.g. C:\dev\netrunner.

⚠
This is not optional. OpenCV (cv2.imread/imwrite) fails silently on paths with non-ASCII characters — a Thai เอกสาร (Documents) folder, for example. Templates just stop matching, with no error message at all. It looks exactly like a broken bot.

OneDrive-synced folders also churn on logs/ and snaps/ writes and can lock files mid-run. Keep the repo outside any synced folder entirely.

2 Run install.bat

Double-click install.bat in the repo root. It runs five checks in order and writes every step to install-log.txt:

  • Confirms the repo folder has main.py, src/, config/, templates/
  • Confirms the install path itself (catches the OneDrive/non-ASCII trap from step 1)
  • Finds a working Python — installs one automatically via winget if none is found, no need to visit python.org
  • Installs opencv-python, numpy, requests, python-dotenv
  • Verifies every package actually imports, not just that pip reported success

If any step shows [X], send install-log.txt — the exact failure is in there. First run can take a few minutes if Python needs downloading; it continues on its own after that.

Manual install (only if install.bat can't run)

Install Python 3.10 or newer from python.org, ticking "Add python.exe to PATH" during setup. If typing python in a terminal opens the Microsoft Store instead of running Python: Settings → Apps → Advanced app settings → App execution aliases — turn off both python.exe entries. Then:

pip install -r requirements.txt

3 Set up LDPlayer

  • Install LDPlayer — version 9 or 14 both work. adb ships bundled at C:\LDPlayer\LDPlayer<version>\adb.exe, no separate install needed.
  • Create an instance and set its resolution to 1920×1080, dpi 240 (must be stopped first to change this): 
    ldconsole modify --index <N> --resolution 1920,1080,240
  • Enable ADB debugging: Settings → Other → ADB debugging → Open local connection.
⚠
1920×1080 is not optional. Every template was cropped at that exact resolution — any other size and matching silently fails. This is the #1 cause of "the bot does nothing / taps randomly." The bot also prints a resolution warning at startup if it detects the wrong size.

Instance-to-port mapping, if you ever need to check manually: 5555 + 2 × instance_index (index 0 → 5555, index 1 → 5557, index 2 → 5559…).

4 .env — optional, usually skip this

adb and the emulator are auto-detected: the engine finds adb on PATH (falling back to the newest C:\LDPlayer\LDPlayer*\adb.exe), then scans ports 5555/5557/5559/5561 for the one running instance. With LDPlayer started, the bots just work — no .env file needed for a single-instance setup.

KeyWhen you need it
NETRUNNER_DEVICESeveral LDPlayer instances running at once — pins which one to use
ADB_PATHadb lives somewhere non-standard
DISCORD_WEBHOOK_URLWant crash/livelock alerts posted to a Discord channel

.env is git-ignored — never commit it. Precedence order: CLI flag > .env > auto-detect > config JSON.

5 Verify before your first run

Run these in order — each one is a gate for the next:

python main.py --list-devices
python main.py --config config/cookierun/coinrun.json --dry-run -v --max-cycles 5

--list-devices should show your instance as device (not offline or empty). --dry-run sends no taps — it only proves capture, template matching, and the state machine wiring all work, safely, before anything touches the game.

6 Game-side preconditions

Each bot expects a specific screen to already be showing before you launch it — see the per-bot section in RUN.md for the exact requirement (Gift Draw popup open, correct Episode selected on home, Friends tab active, and so on).

Playing on a different game account can shift match scores slightly. Most templates score ~1.0 present vs. ~0.35 absent (a wide, safe margin), but heart_empty.png runs a thinner margin (1.0 vs. ~0.75 against a 0.82 threshold). If the heart gate misbehaves specifically, re-crop templates from your own screen — see "Add a new game" in README.md.

7 Running a bot

Every bot has a matching run_*.bat in the repo root — just double-click. Each one launches LDPlayer if needed, opens the game, and starts the loop. Ctrl+C in the console window stops it.

8 Troubleshooting

SymptomCause & fix
Bot does nothing / taps land on random spots Wrong LDPlayer resolution. Must be exactly 1920×1080 — see step 3.
[X] Not set up yet when running a bot Re-run install.bat — the Python it picked doesn't have the packages installed.
OpenBLAS error: Memory allocation still failed after 10 retries numpy's bundled OpenBLAS can fail to grab thread-pool memory on some machines at import time. Fixed by OPENBLAS_NUM_THREADS=1, already set in every run_*.bat and install.bat — make sure you're on the latest pull.
Templates silently never match, no errors anywhere Repo is on a path with non-English characters (often a synced Documents/เอกสาร folder). Move it to an ASCII path — see step 1.
adb stuck offline for more than a minute Don't debug it — create a fresh LDPlayer instance and set its resolution. Auto-detect picks up the new port on its own (clear NETRUNNER_DEVICE from .env first if you'd pinned one).
Bot crashes mid-run with a MemoryError from adb The machine is low on free RAM while LDPlayer + the bot run together. Retries with backoff are already built in (latest pull) — if it still exhausts retries, close other running apps before farming.

9 House rules

  • Never touch the emulator while a bot runs — every tap is a fixed coordinate; a stray click lands wherever it lands.
  • Keep install-log.txt around if something failed — it's the fastest way to diagnose over chat.
  • If you play on a different account than the one templates were cropped from, expect to re-crop a few if match scores look borderline (see step 6).
