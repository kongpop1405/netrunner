Pit Detection — กระโดดข้ามหลุม

netrunner · CookieRun · edge-profile ไม่ใช่ template · engine 3 ไฟล์ + config

rev 1 ตั้งสมมติฐานผิด — แก้แล้วด้วยหลักฐานจากจอจริง:
  • เฝ้า run จริงจนตาย → popup คือ “Save the Cookie · 💎 5 for 1 Pit Lift” = ตกหลุม ไม่ใช่ชน obstacle
  • HP bar เต็มตลอด 52 วินาที — Bonus Time ทำให้ชน obstacle ไม่เจ็บ. Obstacle avoidance จึงแทบไม่มีมูลค่า
  • Pit ไม่มี sprite — มันคือการไม่มีพื้น. Template matching หา “ของที่ไม่มี” ไม่ได้ → Tier 2 ใช้ไม่ได้โดยหลักการ

แยกขาด: มีพื้น ≥142 · หลุม ≤72. ตั้ง EDGE_MIN = 100 · y พื้น = 885 (ground) · y แพลตฟอร์ม = 675

Rกติกาตัดสิน (ต่อ 1 เฟรม)

PROBE_X = 1150 .. 1500        # โซนล่วงหน้า ~0.7-1.1s ข้างหน้าคุกกี้
ground = any(|Sobel_y|(x, 885) > 100  for x in PROBE_X)
plat   = any(|Sobel_y|(x, 675) > 100  for x in PROBE_X)

ถ้า  not ground and not plat   → หลุมข้างหน้า → jump   (cooldown ~700ms)
ถ้า  not ground and plat       → หลุม แต่มีแพลตฟอร์มให้เกาะ → jump
ถ้า  ground                    → พื้นต่อเนื่อง → ไม่ทำอะไร

Slide ยังไม่มี trigger ที่พิสูจน์แล้ว (ยังไม่เคยเห็น run ตายเพราะคานเตี้ย) — primitive เขียนไว้ใน engine แล้ว แต่ยังไม่เสียบใน config จนกว่าจะมีหลักฐานว่าจำเป็น. ไม่เพิ่มสิ่งที่ยังพิสูจน์ไม่ได้ว่าต้องใช้

EEngine changes

1. perceive.py — roi param ✔ ทำแล้ว

Crop ก่อน match แล้ว offset coord กลับเป็น full-frame. ใช้กับ marker ปกติ; ไม่ได้ใช้กับ pit (pit ไม่มี template).

2. act.py — primitive slide ✔ ทำแล้ว

กดค้างปุ่ม Slide (ขวาล่าง 1675,940 — verify จากจอจริง) ด้วย input swipe x y x y hold_ms. เขียนไว้ใช้ภายหลัง.

3. capture.py — grab_band() raw + on-device crop

exec-out "screencap | tail -c +<off> | head -c <n>" → คืน numpy แถบ rows ที่ขอ. ตัด transfer 8.3MB → 0.9MB. ใช้เฉพาะใน dodge loop; state อื่นยังใช้ grab() เดิม (ไม่แตะ template ใด ๆ).

4. fsm.py — state type "dodge"

Tight loop, ไม่ sleep: grab_band → ตัดสิน → jump ถ้าต้อง → วน. ทางออก 2 ทางเสมอ — ทุก N รอบ grab() เต็มเฟรมเช็ค until marker (result_marker → ออก), และ max_ms กันค้าง. ไม่มี self-goto + timeout (pattern นั้น = FsmError crash)

CConfig — cookierun.json

"dodge_run": {
  "dodge": true,
  "until": "result_marker.png",     → goto "run_result"
  "check_until_every": 6,           # เช็ค full-frame ทุก 6 รอบ (~2.5s)
  "max_ms": 300000,                 → goto "guard_not_home"
  "ground_y": 885, "platform_y": 675,
  "probe_x": [1150, 1500], "edge_min": 100,
  "on_pit":  { "type": "jump", "cx": 238, "cy": 940, "rx": 175, "ry": 55 },
  "cooldown_ms": 700,
  "idle": { "type": "tap_xy", "x": 960, "y": 540 },   # Cookie Relay, ทุก ~2s
  "idle_every_ms": 2000
}

guard_not_shop.on_absent: เดิม jump + tap → เปลี่ยนเป็น goto dodge_run. Safety net เดิม (probe chain, coin guard, heart gate, ห้าม gem) ไม่แตะ.

!ความเสี่ยงที่รู้ตัว

  • ยังไม่ทดสอบ: stage ที่ background มีขอบคมแนวนอนพาดผ่าน y=885 (โต๊ะ/ชั้นวาง) → อ่านผิดว่า “มีพื้น” → ไม่กระโดด → ตก. ต้องเก็บสถิติหลาย stage ก่อนเชื่อ threshold
  • ระดับพื้นอาจไม่ใช่ 885 ทุก stage — verify กับ snap ของ episode อื่นก่อน hardcode; ถ้าต่าง ต้องทำ auto-calibrate จากแถวที่คุกกี้ยืน
  • Jump ธรรมดาข้ามหลุมกว้างไม่ได้ — เกมมี double jump. jump ปัจจุบันสุ่ม double 35% → หลุมกว้างอาจต้องบังคับ double เสมอ (วัดหลัง live test)
  • เป้าหมายวัดผล: ระยะเวลา/ระยะทางต่อ run เทียบ baseline (jump มั่ว) — ไม่ใช่ “ไม่ตายเลย”
