01Goal & Scope

run_episode_loop.py --order เป็น required ตอนนี้ — ต้องระบุ ep ล่วงหน้าเสมอ. เปลี่ยนเป็น optional: ไม่ใส่ --order = อ่าน ep ปัจจุบันจาก home banner ด้วย OCR แล้ว farm เฉพาะ ep นั้น ด้วย stop_after_boxes ที่มีอยู่แล้ว (ไม่วนสลับ ep เอง — user เลือก ep เองบน home ก่อนสั่งรัน แล้ว bot รู้เองว่ากำลัง farm ep ไหนโดยไม่ต้องพิมพ์บอก).

02ตำแหน่งที่ต้องอ่าน

Home banner มีป้าย "Episode N" เล็ก ๆ เหนือชื่อตอน — คนละจุดกับ ep<N>_banner.png บนแผนที่ที่มีอยู่แล้ว 7 ตัว (อันนั้นใช้แค่ตอน switch_episode() เลือก ep บนแผนที่). ป้ายบน home ยังไม่เคย crop.

สิ่งที่ต้องทำรายละเอียด
Marker ยึดcrop marker คงที่รอบป้าย (กรอบ/พื้นหลัง) ให้ระบุตำแหน่งได้แบบ relative ไม่ fixed-pixel ตรง ๆ
OCR regionoffset จาก marker ไปยังตัวเลข "N" — pattern เดียวกับ BoxQuitRunner.COUNTER_OFFSET ใน tools/run_toggle.py
Fallbackread_counter() คืน None เมื่ออ่านไม่ออก — ต้อง error message ชัดบอกให้ใช้ --order แทน ห้าม fallback เดา/blind-tap
บทเรียนจาก relic_get_marker: badge/label เลื่อนตำแหน่ง 554px ระหว่าง ep6/ep7 เพราะความยาวชื่อ ep ไม่เท่ากัน — ป้าย "Episode N" อาจเจอปัญหาเดียวกัน (แม้ตัวเลขอยู่ตำแหน่งคงที่กว่าน่าจะ เพราะอยู่ก่อนชื่อ ไม่ใช่หลัง แต่ต้อง verify จริงหลายความยาวชื่อก่อนเชื่อ).

03CLI

# เดิม (ยังใช้ได้เหมือนกัน) — วนตามลำดับที่ระบุ ไม่จบ
python tools/run_episode_loop.py --order 4,2,7,6,5,3,1 --boxes-per-episode 3 --faststart y --boost none --jump y --slide y --relay n --relic y --adb "..."

# ใหม่ — ไม่ระบุ --order = อ่าน ep จาก home แล้ว farm เฉพาะ ep นั้น จบแล้วหยุด (ไม่วน)
python tools/run_episode_loop.py --boxes-per-episode 3 --faststart y --boost none --jump y --slide y --relay n --relic y --adb "..."
# log: "no --order given, reading current episode from home"
# log: "detected Episode 4 (City of Wizards) — farming this episode only"

# OCR อ่านไม่ออก
# error: "could not read episode number from home — pass --order explicitly"
Auto-detect = single-episode run, ไม่ใช่ auto-discover-then-cycle. สอดคล้อง README เดิม ("bot ไม่ navigate episode select, user เลือกเองก่อน") — auto-detect ทำแค่ "รู้ว่ากำลัง farm ep ไหน" เพื่อไม่ต้องพิมพ์ --order ทุกครั้งที่สลับ ep เองแล้วรันซ้ำ.

04Risk / Trade-off

RiskMitigate
ป้าย "Episode N" ตำแหน่งขยับตาม ep locate ด้วย marker คงที่ก่อน offset ไปตัวเลข (เหมือน COUNTER_OFFSET) — verify OCR บนหลาย ep คนละความยาวชื่อก่อนใช้จริง
OCR อ่านเลขผิด (เช่น อ่าน 4 เป็น 1) เชื่อ None เท่านั้นว่า "อ่านไม่ออก" — เลขที่อ่านได้ต้องอยู่ในช่วง 1-7 เท่านั้น ไม่งั้นถือว่า invalid และ fail loud เหมือนอ่านไม่ออก
User รัน auto-detect ตอนยังไม่ได้เลือก ep เอง (อยู่กลาง popup/run) อ่าน ep ได้ก็ต่อเมื่อเห็น home_play_marker ก่อน (จอสะอาดจริง) — ไม่ OCR ทะลุ popup
