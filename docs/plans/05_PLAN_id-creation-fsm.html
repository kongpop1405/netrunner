1. Resolution ชนกัน
doc จดพิกัดที่ 1280×720 แต่ netrunner engine + template ทุกอันของ cookierun อยู่ที่ 1920×1080. cv2.matchTemplate เป็น scale-sensitive → template เก่าใช้ข้ามไม่ได้ และพิกัดใน doc ใช้ตรง ๆ ไม่ได้.
→ ตัดสินใจแล้ว: สร้าง instance ใหม่ที่ 1920×1080 แล้วเดิน flow ใหม่หมด เก็บ coord + template จากจอจริง. พิกัดใน doc ใช้เป็น "ตำแหน่งคร่าว ๆ ว่าปุ่มอยู่มุมไหน" เท่านั้น — ไม่ scale ×1.5 มาใช้ตรง ๆ (นั่นเป็นการเดา).
2. Engine ไม่มี text input — แก้แล้ว (shipped)
เดิม _ACTION_TYPES ไม่มี text. Step 8 (Set Nickname) ต้อง adb shell input text.
→ ทำเสร็จแล้ว: action text อยู่ใน engine จริง — src/config.py (_ACTION_TYPES + _REQUIRED_FIELDS["text"]={"value"}) และ src/act.py (Actor.text() → input text, เคารพ dry_run). เฟส A ด้านล่าง = record ว่าทำอะไรไป ไม่ใช่งานค้าง.
3. Instance base หายหมด
doc อ้าง cookie-idtest(3) / cr-base-loaded(4) / cr-base-preauth(5) แต่ ldconsole list2 ตอนนี้เหลือแค่ index 0-1. ไม่มีจอให้ crop template.
→ ตัดสินใจแล้ว: สร้าง instance ใหม่ 1920×1080 + ติดตั้ง CookieRun แล้วเดิน flow ใหม่ (เฟส B).

  • 2. launch → ติดตั้ง CookieRun Classic (com.devsisters.crg) — apk จาก store ในตัว หรือ ldconsole installapp

  • 5. verify score ทุก template ≥0.95 บนจอที่ควร match ก่อนเขียน config

Design note — flow นี้ต่างจาก bot อื่นตรงไหน
  • Linear ไม่ใช่ loop — bot อื่น (giftdraw/sendlife) วนซ้ำจนหมด resource; อันนี้เดินเส้นเดียวจบแล้ว stop. ไม่มี cycle cap ที่มีความหมาย → --max-cycles ตั้งเผื่อ ๆ ไว้กัน hang อย่างเดียว
  • Age gate ต้องกด + 25 ครั้ง — engine ไม่มี counter → เขียน tap_xy ซ้ำ 25 action ใน on_match เดียว (ยอมได้ ไม่ต้อง state chain)
  • Download 290MB = wait ยาวสุด — เป็นจุดเสี่ยง timeout ที่สุด. ใช้ retry chain รอ ไม่ใช้ self-goto+timeout (= FsmError crash ตาม gotcha ที่รู้แล้ว)
  • ทุก state ที่ absent = "ยังไม่มาถึง" ไม่ใช่ error → default คือ "รอ/retry" ไม่ใช่ "ข้าม"

Dเฟส D — test + launcher

  • --dry-run --max-cycles 20 -v → validate config + match score
  • live capped ทีละช่วง (--start-state ข้ามส่วนที่ผ่านแล้ว — flow นี้เดินซ้ำไม่ได้ ต้อง clone instance ใหม่ทุกครั้งที่ทดสอบเต็ม)
  • run_idcreate.bat — prompt ชื่อ nickname → เขียนลง config ชั่วคราว หรือส่งเป็น arg
  • update RUN.md section ใหม่ + update docs/id-creation-flow.md (instance map เก่าตาย, coord 720p ล้าสมัย)

  • CookieRun ที่ 1080p จะมี layout เดียวกับ 720p ไหม (ปุ่มอาจย้าย ไม่ใช่แค่ scale)
  • Download 290MB ใช้เวลาจริงกี่นาที → กำหนด retry chain ยาวเท่าไหร่
  • nickname ซ้ำได้ไหม / ต้อง random เท่าไหร่
  • ldconsole installapp ติดตั้ง CookieRun ได้ตรง ๆ หรือต้องผ่าน store ในตัว
