01Goal & Scope

--relic y/n ปัจจุบัน: y = claim ทันทีที่ badge ขึ้นแล้ววิ่งต่อ, n = ดองไว้ไม่ claim เลย. เพิ่มโหมดที่ 3 — claim แล้วหยุด process ทันที — สำหรับ "พักเก็บ relic": รอให้ relic ครบพอดีแล้วเลิกงานเอง ไม่ต้องมานั่งคอย log แล้วกด Ctrl+C.

02CLI

# โหมดเดิม (ยังใช้ได้ ไม่เปลี่ยนพฤติกรรม)
--relic y     # claim ทันทีที่ badge ขึ้น แล้ววิ่งต่อ
--relic n     # ดองไว้ ไม่ claim เลย

# โหมดใหม่ — 3-way choice แทน --relic (--relic ยัง alias ไว้กัน breaking change)
--relic-mode claim   # = --relic y เดิม (default)
--relic-mode hoard    # = --relic n เดิม
--relic-mode stop     # claim ทันทีที่ badge ขึ้น แล้วหยุด process ทันที (exit 0)

# ตัวอย่าง: วิ่ง ep 1 จนกว่า relic จะครบแล้วหยุดเอง
python tools/run_episode_loop.py --order 1 --boxes-per-episode 3 --relic-mode stop --faststart y --boost none --jump y --slide y --relay n --adb "..."
--relic และ --relic-mode ห้ามส่งพร้อมกัน — argparse mutually exclusive group ป้องกัน silent override (ไม่ใช่ "ตัวหลังชนะเงียบ ๆ").

03Implementation point

BoxQuitRunner (ใน run_toggle.py) มี transition relic_close → home อยู่แล้วตอน claim สำเร็จจริง (ไม่ใช่แค่ badge ขึ้น). เพิ่ม flag relic_stop_after_claim: bool: เมื่อ true และผ่าน relic_reward สำเร็จ (claim จริงแล้ว) → arm stop เหมือน stop_after_boxes ทำ — ไม่ใช่ _STOP ทันที.

ห้ามซ้ำ bug class ที่เพิ่งแก้ใน stop_after_boxes ไป 2 ตัว:
  • _STOP ก่อน action list รันจบ — เวอร์ชันแรกของ stop_after_boxes return _STOP ที่ run_result ก่อน tap OK ทำงาน ผลคือ Result popup ค้างตลอดกาล (switch_episode() ตัวถัดไป mis-tap ใส่ popup ที่ไม่เคยปิด). Relic ก็เสี่ยงแบบเดียวกัน ถ้า _STOP ที่ relic_reward ทันที — ต้องปล่อยให้ relic_close (X ปิด Relic screen) ทำงานจบก่อน
  • ผูก stop point กับชื่อ state แทน action shape — เวอร์ชันสองผูก stop ไว้ที่ state == "verify_no_enterleague" ซึ่งพังเงียบ ๆ ตอนแทรก probe_relic เข้า chain (Play tap ย้ายไป probe_relic) จนบอทวิ่งเกิน limit ไป 13/3 กล่องกว่าจะมีคนสังเกต. แก้จริงคือ match _PLAY_TAP_XY จาก action shape ไม่ว่า state ไหนถือ tap นั้นอยู่ — relic stop ต้องใช้ pattern เดียวกันตั้งแต่แรก

Flow ที่ต้อง stop ผ่าน

relic_reward (claim สำเร็จจริง, ไม่ใช่แค่ badge)
   ↓ arm relic_stop_at_home = True (เหมือน _stop_at_home เดิม)
relic_close → tap X → home
   ↓ guard chain: verify_no_popup → ... → verify_no_enterleague → probe_relic
probe_relic.on_absent มี Play tap (action shape _PLAY_TAP_XY)
   ↓ match ตรงนี้ → _STOP (จอเคลียร์แล้วจริง ไม่ค้าง popup ไหน)

04Interaction กับ auto-detect episode

ถ้า plan คู่กัน (PLAN_auto-detect-episode.html) ทำเสร็จแล้ว — --relic-mode stop ใช้ร่วมกับ auto-detect ได้ตรง ๆ: ไม่ใส่ --order → อ่าน ep ปัจจุบันจาก home → farm ep นั้น วนจน relic claim สำเร็จ → หยุด. ถ้าใส่ --order หลาย ep → หยุดที่ ep แรกที่ claim สำเร็จ (ไม่ไล่ต่อทุก ep ที่เหลือ).

ทำได้อิสระจากกัน — ถ้า auto-detect ยังไม่เสร็จ --relic-mode stop ก็ยังใช้กับ --order เดิมได้ปกติ ไม่ต้องรอ plan 1 ก่อน.

05Risk / Trade-off

RiskMitigate
Relic ไม่โผล่เลยระหว่าง --order ที่กำหนด (fragment ไม่ครบ) ตั้งใจไว้ — process วิ่งต่อไปเรื่อย ๆ ตาม order/max-cycles ปกติจนกว่า relic จะครบ ไม่ error ไม่ timeout พิเศษ (เหมือนพฤติกรรม --relic y เดิม)
stop ยิงก่อนจอเคลียร์จริง (ซ้ำ bug เดิม) ใช้ action-shape matching กับ _PLAY_TAP_XY เป๊ะตาม pattern ที่ verify แล้วใน stop_after_boxes — ห้ามคิด pattern ใหม่
--relic/--relic-mode ส่งพร้อมกันจน override เงียบ argparse mutually exclusive group — error ทันทีถ้าส่งทั้งคู่
